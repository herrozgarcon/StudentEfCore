# Phase 6: Course Entity and Migration

## 1. Objective

Introduce Course management into the Student Course Management application using Entity Framework Core.

## 2. Course Entity

The `Course` entity represents a course offered by the institution.

Properties:

- `CourseId` — Primary key generated by SQL Server.
- `CourseName` — Required course name with a maximum length of 100 characters.
- `Credits` — Required value between 1 and 6.
- `IsActive` — Indicates whether the course is active; defaults to `true`.

## 3. Fluent API Configuration

The `AppDbContext` configures the Course entity using Fluent API.

- Maps the entity to the `Courses` table.
- Requires `CourseName` and limits its length to 100 characters.
- Creates a unique index on `CourseName`.
- Adds a database check constraint requiring credits between 1 and 6.
- Configures `IsActive` with a default value of `true`.

## 4. Migration

Migration name: `AddCourseEntity`

The migration creates the `Courses` table, its primary key, the credits check constraint, and the unique index on `CourseName`.

Commands used:

```bash
dotnet ef migrations add AddCourseEntity
dotnet ef database update
```

## 5. Repository Layer

`CourseRepository` performs database operations through `AppDbContext`.

Implemented operations:

- Add a course.
- Retrieve all courses.
- Retrieve a course by ID.
- Update a course.
- Delete a course.

`AsNoTracking()` is used when retrieving all courses because those results are read-only.

## 6. Service Layer

`CourseService` delegates course operations to `CourseRepository`.

This separates application operations from database access.

## 7. Menu Layer

`CourseMenu` provides the console interface for course management.

Available operations:

1. Add Course
2. View All Courses
3. View Course By ID
4. Update Course
5. Delete Course
0. Back to Main Menu

The menu validates course credits before saving and handles database update errors.

## 8. Program.cs Refactoring

The main entry point now creates repositories, services, and menu objects.

It displays the main menu and delegates department, student, and course operations to their respective menu classes.

The application does not yet use dependency injection. That refactoring is planned for Phase 9.

## 9. Phase 6 Outcome

- Course entity configured.
- Course migration applied.
- Course repository implemented.
- Course service implemented.
- Course menu implemented.
- Main menu refactored.
- Application build and menu operation verified.
